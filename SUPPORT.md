# Support

## How to get help

### 1. Check the Documentation
Before asking, please check:
- [README.md](./README.md) for setup and overview.
- [API_DOCUMENTATION.md](./API_DOCUMENTATION.md) for endpoint details.
- [Troubleshooting Guide](.claude/commands/troubleshoot.md) (or run `/troubleshoot` if using Claude Code).
- [GitHub Discussions](https://github.com/alexandergg/QPrisma/discussions) (if enabled).

### 2. Search Existing Issues
Your problem may have already been reported. Please search [Issues](https://github.com/alexandergg/QPrisma/issues).

### 3. Ask Questions
For general usage questions, "how-to" advice, or architectural discussions, please use **GitHub Discussions** instead of opening an Issue.
- Tag your discussion with `Q&A`.

### 4. Report Bugs
If you find a bug in the source code, open an [Issue](https://github.com/alexandergg/QPrisma/issues/new?template=bug_report.md).
- Please follow the Bug Report template.
- Include reproduction steps and logs.

### 5. Security Vulnerabilities
**DO NOT** report security vulnerabilities in public issues.
Please refer to our [Security Policy](./SECURITY.md) for reporting instructions.

## Professional Services
QPrisma is an open-source project. If you require commercial support, custom integration, or SLAs, please contact the maintainers directly.
